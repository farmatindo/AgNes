# AgNeS — Agromedis Neurodiversitas Scoring

Platform skoring berbasis web untuk skrining risiko potensi neurodiversitas pada anak, dikembangkan oleh **Tim PANAH Universitas Jember** sebagai luaran Penelitian Terapan – Luaran Model (DPPM Kemdiktisaintek, 2025).

Penilaian mencakup empat domain: paparan karena pekerjaan, paparan karena lingkungan, keberadaan tetangga dengan neurodiversitas, dan pendidikan ayah. Hasil skrining dikategorikan menjadi Risiko Rendah, Sedang, atau Tinggi.

Hasil AgNeS adalah skrining risiko, bukan diagnosis.
